# Electro-Magnetic Simulator (静電気・磁力シミュレーター)

TypeScript と HTML5 Canvas を使用した、2次元空間における電荷粒子の動的物理シミュレーターです。
クーロン力（静電気力）とローレンツ力（磁場から受ける力）をリアルタイムに計算し、描画します。

## 特徴

- **高精度な物理演算**: エネルギー保存に優れた「ベルレ積分（Verlet Integration）」を採用し、粒子が急接近した際も軌道が安定します。
- **リアルタイム・コントロール**: 画面上のスライダーから、クーロン力係数、一様磁場の強さ、各粒子の電荷量を動的に変更できます。
- **直感的なUI**: スタート/ストップ機能および、いつでも初期状態からやり直せるリセット機能を搭載しています。

## 技術スタック

- TypeScript
- HTML5 Canvas (2D Context)
- Vite (開発サーバー & ビルドツール)

ターミナルに表示される URL（例: http://localhost:5173/）にブラウザでアクセスしてください。物理モデルについて静電気力: クーロンの法則 $F = k \frac{q_1 q_2}{r^2}$ に基づき、同符号なら反発、異符号なら引き合います。磁力: ローレンツ力 $\vec{F} = q(\vec{v} \times \vec{B})$ に基づき、粒子の進行方向に対して垂直な力を与えて軌道をカーブさせます。
